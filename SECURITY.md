# Security Policy

## Supported Versions
A política cobre a versão corrente do repositório principal.

## Reporting a Vulnerability
Relate vulnerabilidades de forma responsável para `contato@techcodecompany.com`.

Inclua:
- descrição do problema
- impacto observado
- passos de reprodução
- versão/commit afetado
- sugestão de mitigação, se houver

Evite divulgar publicamente vulnerabilidades antes da correção.
