# Contributing

## Setup
```bash
npm install
npm run dev
```

## Antes de abrir PR
Execute:
```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Diretrizes
- mantenha o escopo pequeno
- preserve performance e acessibilidade
- adicione ou ajuste testes ao alterar fluxos críticos
- não inclua segredos, arquivos locais ou artefatos gerados
